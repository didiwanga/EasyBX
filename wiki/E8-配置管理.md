# 配置管理（基础件其二）

> 统一配置存储：JSON 多文件 + 全局/每账号/每账号自动化三种作用域 + 单例 ConfigManager 访问。
> 配合 D4 多账号、各自动化模块配置文件。

## 一、存储结构（JSON 多文件）
```
%APPDATA%\XkxClient\         # 所有配置根目录
├── config.json              # 全局配置（窗口/字体/托盘/通用）
├── layout.json              # 布局/停靠面板位置（非账号相关全局）
├── config\                  # 自动化运行缓存与定义：timers/scripts/map_cache 等（见 E6/E8脚本/地图）
├── accounts\                # 每账号目录
│   └── <account_id>\
│       ├── config.json      # 该账号配置（编码/服务器/初始化命令等）
│       ├── automation.json  # 该账号自动化（触发器/别名/定时器/宏/脚本 定义）
│       └── ...              # 该账号自动化定义分开文件（automation_trigger / _alias / _macro / _timer / _script）
```
> 触发器/宏捕获的 **变量仅运行期内存、不持久化**（清客户端即清除，见 B3）；如需初始值可在账号配置中定义。

## 二、作用域
| 作用域 | 用途 | 存储 |
|---|---|---|
| 全局 | 字体/窗口/托盘/通用/布局 | `config.json` + `layout.json` |
| 每账号 | 编码/服务器/初始化命令/D4 | `accounts\{id}\config.json` |
| 每账号自动化 | 触发器/别名/定时器/宏/脚本/变量 | `accounts\{id}\automation*.json` |

- 自动化定义在「账号共享」未勾选时存账号目录；勾选共享存全局（见 B9/D4 可见性规则）。

## 三、单例 ConfigManager
```python
class ConfigManager(QObject):
    _instance
    def get(scope: 'global'|account, path: str, default=None)
    def set(scope, path, value) -> 自动持久化
    def save(scope) / load(scope)
    def account(core_id) -> 账号作用域对象
    # 全局单例 ConfigManager()
```

- 模块通过 `ConfigManager.get("layout", "central_split", False)` 访问，不直接碰文件。
- 广播 `config.changed(scope, path)` 事件（走 EventBus），UI/模块响应刷新。

## 三、账号作用域对象
```python
class ConfigScope:
    path: Path, data: dict
    get/set/save/load
    # 该账号的自动化子配置读写
```

## 四、持久化策略
- 写入即时落盘（防丢失）；有防崩（write temp + rename）。
- 只读时也挂载；配置恢复默认（reset）可回到出厂。

## 五、与事件总线集成
- 配置变更发布 `config.changed`（带 scope+path），供 UI/模块热更新。
