# B8 自动化菜单：Lua 脚本（定稿）

## 功能入口（自动化菜单）
- **Lua 脚本编辑器**：独立窗口，QScintilla 语法高亮 + 行号，保存 / 运行。
- **导入脚本**：选 `.lua` 文件 → 拷入 `lua/` 目录并自动注册。
- **运行**：独立 Lua 运行时，通过 API 暴露给脚本。

## 编辑器实现
- 选型：**QScintilla**（第三方依赖，PyQt6 配套 `QScintilla`）。
- 窗口：编辑器 + 运行输出区（脚本 print 输出、错误堆栈）。

## Lua 运行时 API（大纲，待细化）
- `send(cmd)`：向游戏发送命令
- `print(text)`：输出到客户端窗口
- 触发器 / 别名 / 定时器：脚本可注册与注销
- 变量：脚本间共享键值

## 脚本生命周期
- 存储：`lua/*.lua`
- 自动加载：启用脚本随客户端启动自动运行
- 手动运行：编辑器内运行 / 菜单项

## 依赖
- 新增第三方包：`QScintilla`（语法高亮）、`lupa` 或 Lua 绑定（待定运行时）。
