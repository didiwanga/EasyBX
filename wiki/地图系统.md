> 旧项目仅作「功能目标」参考，**不沿用其设计/源码**，尤其本地地图绘制完全不采用旧版方案。
> **2026-08-17：服务端地图（47.104.0.91/api/map/）已全部清空（代码/DB/备份），地图改为纯本地**（采集→本地缓存→本地寻路），不再依赖服务器。

## 架构全景（纯本地）
```
pkuxkx --GMCP.Move--> [MapSync: 采集] --> 本地缓存 %APPDATA%\XkxClient\config\map_cache.json
pkuxkx --look--> [LookCapture: 房间细节] --> 本地缓存
                                                    │
                          ┌───────────────┬─────────┴────────┬──────────────┐
                          ▼               ▼                  ▼              ▼
                  房间拓扑画布      区域拓扑画布          世界静态图       [Navi: 寻路+walk]
```

## 一、数据采集
### MapSync（本地采集）
- 订阅 `GMCP.Move`：`result=true` 时从 `short`+`dir` 生成 room+边；`result=false`(撞墙)不更新。
- 监听用户发出的方向命令记 `_pending_dir`（短名规范化）。
- 悬空出口（look 见但未走）入 dirty。
- 采集结果写入本地缓存；不向服务器上报。

### LookCapture（房间细节）
- 移动到未记录房间 / 用户右键**手动**触发 look（不自动刷屏）。
- 解析 description + objects（NPC/玩家/物品/可交互物，格式见 B 文档 look 解析层）。
- 结果入本地缓存。

### MapCache（本地缓存）
- 启动 500ms + 60s 周期落盘 `%APPDATA%\XkxClient\config\map_cache.json`，离线可看。
- 布局坐标 `pos_x/pos_y` 本地保存，用于 route 的 distance 有效。

### 编码
- 全程 UTF-8；中文必须正确，杜绝乱码。
- 解析容错：JSON 双重编码 + ANSI 清洗（复用 C/GMCP 容错思路）。

## 二、导航（重点：真正可走、接入自动化）
### 路径来源（纯本地）
1. 本地 BFS：用本地拓扑（MapCache.edges）先算。
2. 无路 → 提示无路，不盲走。

### 服务器 node 路径列表（导航目的地 dock）
- 主窗口发送 `node`，捕获服务器返回的玩家定义路径表格（名称+目的地），双击/回车发送 `node walk <名称>`。
- **表格行不上主输出**（session 拦截含框线字符的行）。
- **分页看门狗**：途中出现的 `== 未完继续 X% ==` 分页提示 → 续命超时等下一页；
  每条新行也重置 20s 捕获超时（长表格不被误杀）；表头损坏/表头页丢失时按数据行兜底识别；
  移动静止 3s 自动刷新（用户正忙：输入框聚焦/行走中/宏运行 → 跳过静默刷新）。
- 空路径提示（「这里没有玩家定义的路径」）或表尾框线 `└…` → 结束捕获。

### 自动 walk（新功能，旧版只画不走）
- 得到方向序列 → 转命令 → **逐条发送**。
- 步进节奏**可配置**，默认 ~1.5s/步（范围 0.8~3s 可调）。
- **每步等 GMCP.Move 确认**：`result=false` 立即停下 + 报错；连续超时也停。
- 交互：停止/暂停按钮可见；当前步高亮。

### 导航接入自动化
- 导航状态事件（开始 / 每步 / 到达 / 卡住 / 停止）入事件总线，供触发器/宏订阅。
- **到达目标可触发命令序列**（配置目标点 → 到达后发初始化命令）。

### 边界
- 特殊方向 enter/out/up/down/nu..wd 纳入方向集与反向表。
- 单向边（只有去没有回）在地图标示，walk 遇单向门单向按路径走。

## 三、呈现（重点改进，不沿用旧版）
### 本地房间拓扑 <--> 矢量交互画布（QGraphicsScene）
- 节点=房间，边=方向连线。
- **交互**：滚轮缩放 / 拖拽平移 / 节点点击查看信息(名称/描述/NPC/出口) / 搜索框定位。
- **布局**：方向感知 BFS（8 方位 + 上下），同方向并列不重叠，冲突螺旋避让；单向边短画暗色、垂直方向虚线；玩家当前位置高亮（金环）。
- 质量：保持格子对齐，避免旧版乱象。

### 区域拓扑 <--> 矢量画布
- 力导向布局；区域节点=区域，跨区域寻路高亮；双击节点选目标。
- 数据来自本地采集的区域归类。

### 世界静态图
- worldmap.png，等比缩放，滚轮缩放/拖动/重置（R 已规划）。叠加区域/城市占位标记（可选）。

## 四、特殊房间 / NPC / 区域
- **特殊房识别**：马车行/渡口等，靠 look 描述关键词，标注类型（如「马车行」可跨城、「渡口」可渡河）。
- **NPC 查询**：本地 look objects 检索。
- **区域归类**：本地采集文本辅助。

## 五、模块划分（新文件，不沿用旧代码）
- `core/map/`：map_sync / map_cache / look_capture / navigate
- `ui/map/`：local_map_widget（矢量）、world_map_widget、world_image
- 纯本地存储后端（map_cache.json）；本地解析逻辑从零实现。
