# D 多账号与自动登录（定稿）

## D1 账号管理
- **账号模型**：
  | 字段 | 说明 |
  |------|------|
  | name | 显示名 |
  | server | 引用 A1 服务器配置 |
  | username | 英文名 |
  | password | 加密存储 |
  | email | 邮箱地址（便于用户记忆，可选） |
  | 自动登录 | 是否启用自动登录 |
  | 登录后信息 | 登录后经 GMCP 回填：中文名 / 门派 / 级别 / 头衔 |
- **登录后信息回填**：当前账号登录后，通过 GMCP（Status 的 name/title/family/family_name/level，见 C）获取中文名、门派、级别、头衔，写回账号信息持久化。
- **存储**：本地配置文件，密码**加密**存储。
  - 密码加/解密用**固定算法**，无需额外主密码（便捷优先，安全适中）。
  - 明文仅运行时在内存中解密，不写盘。
- **UI**：菜单连接/账号管理（增删改，可编辑邮箱等）+ 快捷切换下拉。
- **快捷切换**：从账号库选中账号 → 执行「断开当前连接 → 连接该账号的服务器 → 选定账号自动登录」。
- **切换（多标签）**：**已由 D4 多标签页取代**——一个主窗口多标签，每标签独立连接/输出/自动化，可同时登录多账号，切标签即看对应账号。

## D2 自动登录（完整）
完整自动登录 = 自动走完整握手 + 等提示发送 + 登录后初始化。

### 握手流程（复用 A2/A4）
1. 编码 → 按账号 encoding 直接回 1/2/3（A2）。
2. 等「英文名」提示 → 发 username。
3. 等「密码」提示 → 发 decrypt(password)。
4. 登录完成后 → 执行登录后初始化命令序列。

### 提示词等待机制（关键）
- **不盲目发送**：发送账号/密码前先等待服务器对应提示词出现。
- 提示词可配置（白/黑名单），默认内置常见词（如 `请输入英文名字`/`password:` 等）。
- 防止错位：提示词不匹配 → 不发送，报错并停止/重试。

### 登录后初始化命令序列（可配置）
- 登录完成后自动执行配置的命令序列（`;` 分隔多命令，同 B6 输入栏机制）。
- 默认含自动化 GMCP 订阅（`tune gmcp ... on`，见 C），可追加如 `hp`/`wimpy 30` 等。
- 可随账号持久化；允许为空。

### 失败/超时
- 登录步骤超时/提示词不匹配 → 报错，停止或进入 A4 重试策略。

## 关联
- 复用 A4 自动重连（重连后自动重登）、A2 编码、A1 配置、C（GMCP 握手 + 订阅）。
