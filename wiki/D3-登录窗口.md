# D3 登录窗口（定稿）

## 启动流程
1. 运行客户端 → **先显示登录窗口**（不直接进主窗口）。
2. 用户在登录窗口选择服务器/编码、输入用户名密码 → 点「登录」。
3. 关闭登录窗口 → 打开主窗口 → 主窗口按所选信息执行连接 + 完整登录流程（D2）。

## 登录窗口内容
| 控件 | 说明 |
|------|------|
| 服务器选择 | 下拉：内置服务器 + 用户自定义；默认选中北侠 8080 |
| 自定义服务器 | 添加/编辑/删除服务器对话框（A1 配置），持久化 |
| 编码选择 | GBK 等；默认 GBK；按所选服务器自动匹配已知编码 |
| 账号下拉 | 可编辑下拉：已存账号（D1 账号库）+ 手动输入新 ID；选中已存账号自动回填用户名/密码/登录后命令/自动登录 |
| 用户名 | 输入框 |
| 密码 | 输入框（掩码显示，带「显示」切换钮） |
| 记住到账号库 | 勾选则用户名+加密密码+登录后命令+自动登录写 D1 账号库 |
| 登录后命令 | 登录完成后自动发送的命令序列（`;` 分隔，可空） |
| 自动登录 | 连接后自动完成 D2 完整登录流程 |
| 注册按钮 | 连接服务器，被提示「请输入new」时自动发 new，之后交给用户 |
| 连接按钮 | 关闭登录窗、开主窗、按所选信息连接 + 登录 |

## 上次登录自动回填
- 打开登录窗即回填上一次成功连接的账号（config `login.last`）：若该账号在账号库 → 用账号库数据；否则回填用户名/密码（加密存储解密后）。

## 编码自动匹配规则
- 已知服务器（内置）→ 自动匹配其默认编码：
  - 北侠 8080 → GBK
  - 北侠 8081 → UTF8
- 服务器编码未知（用户自定义/未配置）→ 默认 GBK，或允许用户手动改选。

## 与 A1/D1 的关系
- 自定义服务器写入 A1 服务器配置（持久化），下次出现在下拉中。
- 登录窗与 D1 账号库**打通（方案 B）**：
  - 登录窗提供「记住到账号库 / 保存此账号」选项。
  - 勾选后用户名 + 加密密码 + 登录后命令 + 自动登录保存到 D1 账号库，供后续「快捷切换 / 自动登录」使用。
  - 未勾选则本次密码仅当前会话使用，不入库。
  - 已存账号可在登录窗下拉/列表快捷填充。
- **账号管理**（主窗口 账号→编辑账户信息…，AccountManagerDialog）：
  - 已存账号增/删/改，账号信息含：账号ID（显示名）、用户名、密码（加密）、登录后命令、自动登录开关。
  - 修改后即时写 accounts.json；改 ID 时先删除旧账号再存新 ID。

## 验收
- [ ] 启动先显示登录窗口，登录后才开主窗口
- [ ] 服务器下拉含内置+自定义，默认北侠 8080；自定义地址端口持久化
- [ ] 编码默认 GBK；选择已知服务器自动匹配编码；未知服务器可手动
- [ ] 连接按钮关闭登录窗、打开主窗并完成登录流程
- [ ] 勾选「记住到账号库」保存到 D1；未勾选本次密码不保存；已存账号可快捷填充
- [ ] 账号管理对话框增/删/改已存账号，改 ID 即时生效
- [ ] 打开登录窗自动回填上次登录账号（login.last）
