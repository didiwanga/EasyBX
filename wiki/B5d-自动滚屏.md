# B5d 自动滚屏状态机（定稿）

## 模式
- **跟随模式（默认）**：输出自动滚到最新，新行到达即滚到底。
- **暂停模式**：用户向上翻（离开底部余量）→ 暂停自动滚屏，保持当前查看位置。
- **恢复**：滚回接近底部（底部余量内）→ 恢复跟随。

## 底部余量阈值
- 用接近底部的**余量判定**，不必绝对到底：距底 ≤ 一个逻辑行或少量 px（阈值可调）。
- 避免输入法/边缘场景误判。

## 新消息浮动按钮
- 仅当**暂停跟随且出现新行**时显示，浮于输出区右下角。
- 内容：`新消息 N`（N = 暂停期间新增条数，实时累加）。
- 点击 → 回到底部 + 恢复跟随 + N 清零 + **按钮消失**。
- 无新行 或 已恢复跟随 → 按钮隐藏。

## 强制回底
- **Ctrl+End**（或「到底部」按钮）：强制回到底部并恢复跟随。

## 滚动行为
- 仅跟随模式时新行才触发滚动；暂停模式彻底不移动滚动条。

## 与 B5 协调
- 与 5000 行窗口/20000 历史、分屏上下、Ctrl+F 搜索分屏共存。
- 搜索分屏独立于主屏滚动状态。

## 验收
- [ ] 默认跟随；上翻暂停；回到底部余量恢复
- [ ] 暂停+新行显示「新消息 N」浮动按钮；点击回底+恢复+计数清零+消失
- [ ] Ctrl+End 强制回底恢复
- [ ] 暂停时新滚动条不被移动
