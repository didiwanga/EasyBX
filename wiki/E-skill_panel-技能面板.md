# E-skill_panel 技能面板（定稿）

> 数据已成：经 8080+GBK 实测，**服务器无 `GMCP.Combat/Skills` 模块**（低等级无触发场景下仅 `System/Move/Status` 三个模块）。
> 策略（用户确认）：**文本命令解析为主通道，GMCP 留接口**。双通道避免未来 GMCP 有数据时重构。

## 一、数据源策略
- **主**：`skills` 命令返回的技能列表文本（结构稳定，见下方真实样例）。
- **辅/状态**：`jifa`（三系启用比率）、`en` / `score` 的部分字段、GMCP.Status（qi/jing/level）。
- **GMCP 接口**：预留 `SkillPanel.on_gmcp(msg)` 挂点，收到 `GMCP.Skills/Combat/Buff` 时更新；当前不实现消费。

## 二、skills 文本样例（真实采集，UTF-8 无损）
```
┌───技能列表(共十项)────────────┬──────┬───────┐
│技能                                          │描述       │级别/上限     │
├───三项杂学────────────────┼──────┼───────┤
│  招魂术(evocation)                           │不堪一击    │   14.00/36   │
│  读书写字(literate)                          │新学乍用    │   25.16/-    │
│  道家养生术(taoism)                          │初窥门径    │   60.01/-    │
├───五项基本功夫──────────────┼──────┼───────┤
│  基本拳法(cuff)                              │毫不足虑    │   26.37/36   │
│  基本轻功(dodge)                             │毫不足虑    │   35.00/36   │
│  基本内功(force)                             │毫不足虑    │   35.00/36   │
│  基本招架(parry)                             │毫不足虑    │   32.47/36   │
│  基本剑法(sword)                             │毫不足虑    │   36.00/36   │
├───二项特殊功夫──────────────┼──────┼───────┤
│□太极神功(taiji-shengong)        │不堪一击    │   11.55/36   │
│□梯云纵(tiyunzong)              │毫不足虑    │   36.00/36   │
├───────────────────────┴──────┴───────┤
│共使用了10.5个技能槽位，空余槽位(19.5)。级别上限：-5.56%。│
└─────────────────────────────北大侠客行────┘
```

### 解析规则（逐行正则）
- 分组头：`├───(.+?)┼` → 分组名「三项杂学 / 五项基本功夫 / 三项特殊功法」。
- 技能行：`│(.+?)\(([a-z\-]+)\).*?│\s*([\w]+)\s*│\s*([\d.]+)/([\d.\-]+)` 
  - 中文名（含□=已启用标记） / 英文 key / 描述短语 / 当前级别 / 上限级别。
  - `-` 表示无上限（读书、养生等）。
- 底部汇总：`共使用了([\d.]+)个技能槽位，空余槽位\(([\d.]+)\)`.

## 三、数据结构 Skill 与 SkillPanel
```python
class Skill:
    key: str            # 'dodge' / 'taiji-shengong'
    name: str           # 基本轻功 / 太极神功
    category: str       # 杂学 / 基本功夫 / 特殊功法
    level: float        # 35.00
    cap: float | None   # 36 或 None(上限为-)
    enabled: bool       # □=True 已启用

class SkillPanel(QtWidgets.QWidget):   # 每个账号标签页内独立实例
    skills: list[Skill]
    # GMCP 接口
    def on_gmcp(self, msg): ...         # 预留
    def refresh(self):
        send_command('skills')          # 发送刷新
        # 收到解析结果后 rebuild()
```

## 四、解析管线
```
raw_text ──(skills parser)──> list[Skill] ──> SkillPanel.rebuild()
   触发时机：登录完成 / skills 命令返回 / GMCP.Skills 到达(若有)
```

## 五、UI（每个标签页的 dock，D4 关联）
- 列表：按分组折叠；每组一行标头（分组名 + 计数）。
- 每技能一行：`名称`、`描述(类)`、`等级/上限`、`已启用`勾选标记。
- 顶部悬浮条：`技能槽 10.5 / 30`。未满提示当前剩余容量。
- 点技能行：可发送对应 `skills <key>` / 打开脚本挂钩（可选）。

## 6、与 E7 look 关联
- 技能面板并入 E7 look 解析的数据流：对应账号标签只显示该账号的 skill 列表（D4 每标签一个）。

## 7、进度条数据条规约（全局引用 B7）
- 技能等级若以进度条显示，复用 B7【渲染规约：进度条钳制】：cur>=max 恒 100%、cur<max 按比。
- 技能通常显示文本 `等级/上限`，不强制进度条；若加条须遵循以上钳制。
