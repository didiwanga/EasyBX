# A4 连接管理（定稿）

## 连接生命周期
典型连接 → GMCP 握手（C1：连接时 DO 0xC9 + Core.Hello）→ 编码(回1/2/3) → 账号 → 密码 →
登录成功 → MXP/SDRAW 探测应答（A3）→ 自动 tune 订阅（C）+ 登录后初始化命令序列（D2）。

## 自动重连
- 自动重连开关默认开。
- **退避间隔**：3s → 6s → 12s → 60s 上限，按失败次数递增；成功后清零。
- 重连到同一服务器后自动走完整登录流程（自动重登）。
- 可手动取消一次重连。

## 连接状态
- 状态栏展示：连接中 / 已连接 / 重连中(倒计时/次数) / 中断。供 B7 状态栏与 UI 层订阅。

## 多账号
> **已由 D4 多标签页取代**：一个主窗口多标签，每标签独立连接，可同时登录多账号。
> （原「单窗口切换重连，不建多标签」已废弃。）
