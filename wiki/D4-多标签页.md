# D4 多标签页（同时登录多账号，定稿）

> 用户选 A 方案：一个主窗口，每个账号一个标签页，各自独立连接/输出/自动化。
> **推翻 A4「不建多标签」**，A4 相关描述以本文档为准。

## 结构
- 一个主窗口 + 顶部标签栏（QTabWidget 或自定义）。
- **每标签页 = 一个账号会话实例**：
  | 实例内容 | 说明 |
  |---------|------|
  | 独立连接 | 独立 socket / 连接状态 |
  | 独立输出窗口 | 各自输出缓冲、历史、ANSI |
  | 独立自动化 | 触发器/别名/定时器/宏/Lua 完全独立 |
  | 独立状态 | 角色状态(state)、GMCP 数据 |
- 标签页可增开（登录另一账号）、关闭（登出）、重连。
- 工具栏「账号」可快速新增标签（账号库选择 → 自动登录）。

## 隔离边界
- **自动化定义的可见范围（按"账号共享"属性）**：
  - 每个触发器/别名/宏/定时器/Lua 创建时有一项 **「账号共享」** 勾选：
    - **勾选共享** → 所有账号登录后都可见可用。
    - **不勾选** → 绑定创建时所在账号，仅该账号登录时显示和使用。
- **运行时独立**：无论是否共享，**每个标签各自实例化**该定义、**各自启停**，互不影响。
  - 同一份共享定义，在两个已登录标签里各有独立运行实例。
  - 全局开关（trigger_on 等）按标签各自生效。
- **标签页之间不共享"运行状态"**，只共享"定义配置"。
- 输出窗口/连接/状态/GMCP 数据依旧每标签独立。

## 编辑与共享
- 触发器/别名/宏/定时器/Lua 编辑器创建新项时提供「账号共享」复选框（默认按需，未勾=绑定当前账号）。
- 共享项编辑后对已登录的各账号标签**在下次/即时重载定义**后生效（重载时机见验收，默认即时生效由各标签读取最新定义）。

## Dock 跟随
- 状态面板 / 移动控制 / 快捷动作 / 命令速查等 **dock 随当前标签切换**，显示当前活动账号的数据。
- 切换标签 → 所有 dock 内容刷新为对应账号。

## 登录流程
- 每个标签独立走 D2 完整自动登录。
- 标签页登录失败不影响其他标签。

## 验收
- [ ] 主窗口多标签，可增开/关闭/重连每账号
- [ ] 每标签连接、输出、状态独立
- [ ] 自动化定义可按「账号共享」勾选：共享项所有账号可见可用，未勾选项仅绑定账号可见
- [ ] 无论共享与否，每标签各自实例化运行、各自启停
- [ ] 全局开关按标签各自生效
- [ ] 切换标签时所有 dock 跟随更新
- [ ] 各标签自动登录互不影响
