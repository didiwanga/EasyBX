# B3c MUD 函数 `##` DSL（定稿 v2）

## 定位
以 `##` 前缀的脚本 DSL（求值器），在命令输入框执行，也可被触发器/宏/定时器的命令引用。

## 执行入口
- 输入框输入 `## <表达式>` → 求值执行。
- 支持：函数调用、对象属性访问、字面值（字符串/数字/列表）、链式调用。

### 能力放开口（相比旧项目更开放，已定稿）
- **控制流（完整）**：if / else / for / while 循环；比较运算（`=`、`!=`、`>`、`<` 等）；逻辑运算（且 and / 或 or）——**全部放开**。
- **算术运算（完整）**：`+ - * /` 与括号。
- **不做函数定义**：DSL 不提供 def/函数定义，能力由 API 命名空间提供。

## 变量体系（与 {变量} 统一）
- **A 统一**：`##` DSL 变量 与 触发器/宏捕获的 `{变量}` 为**同一变量引擎**。
  - DSL 可读写 `{变量}`；触发器/宏捕获写入的变量，DSL 可见；DSL 写入也对触发器/宏可见。
  - 变量仅运行期内存（沿用 B3）。

## API 命名空间
- **sys.***：客户端能力（send / setInput / getVariable / setVariable 等）。
- **com.***：共享变量命名空间（多脚本间共享）。
- **my.***：个人变量命名空间（个人脚本私有）。

## 手册面板（数据文件驱动）
- **C 数据文件**：API 手册从数据文件加载（分类/签名/参数/示例），UI 零硬编码。
- 与 B6 命令速查同理，数据文件驱动、可随时增补。

## Tab 补全
- 输入 `##` 后 Tab 补全 `sys.` / `com.` / `my.` 前缀。

## 已确认（定稿）
- **B 放开范围**：控制流与算术**完整放开**——if/else + for/while 循环、比较运算（且/或）、算术（+ - * /）。
- **不做函数定义（def）**：能力仅由 sys/com/my 命名空间提供。

## 验收
- [ ] 输入框 `## 表达式` 求值执行
- [ ] 控制流 if/else/for/while + 比较 + 且/或 可用
- [ ] 算术 + - * / 与括号可用
- [ ] DSL 变量与 {变量} 同一引擎互通
- [ ] sys/com/my 命名空间工作；com 共享 my 个人
- [ ] 手册由数据文件驱动
- [ ] Tab 补全 sys/com/my 前缀
