# B5 输出窗口（主文档，定稿）

> 空格/等宽/换行三条硬约束见《B5-输出空格等宽约束.md》，本文件是功能主线。

## 组件选型
- `QPlainTextEdit`（非 QTextEdit，避免空格折叠/HTML 合并），ANSI 通过 `mergeCharFormat` 分段上色。
- 中英等宽一致的字体（如 NSimSun/新宋体）保证边框对齐，字体可在设置更换（B5-2 字体项）。

## 基础行为
- 不换行（超长行水平滚动）。
- 显示上限 5000 行窗口 / 20000 条历史（回看更早历史时加载）。

## 自动翻页（B5-3）
- 默认开：正则扫描 `== 未完继续 (\d+)% ==`，解析百分比。
- 命中则自动发送空命令继续翻页；超过 20 页停下，等待手动。
- 翻页按钮可手动上下。

## 搜索（Ctrl+F）
- 自动打开分屏 + 高亮所有命中 + ⬆️⬇️ 快捷定位。
- 分屏仅上下显示；历史"拖到底自动加载 + 回到底跟随"。

## 清屏
- 清屏按钮/右键清屏；清屏不清历史（历史可翻回）。

## B5-2 右键菜单
- 复制 / 搜索 / 清屏 / 字体（仅等宽选项 + 可调字号）/ 新建触发器 / 添加到过滤器。
- 选中文本右键「新建触发器」自动预填，默认「包含匹配」。

## B5-5 过滤
- 可对输出过滤（如按频道/关键字）；「添加到过滤器」将选中文本过滤入过滤器。
- 配 B8 Lua 可扩展。

## 折叠行（状态/信息行）
- 支持对触发器命中等产生的重复状态/信息行做**折叠**（append_fold_line）：同一内容出现多次时折叠为一行并附带计数。
- 折叠行用报告颜色区分；点击可展开/还原；折叠计数随命中累加（与 B3 计数器同源）。

## 验收
- [ ] 5000 行窗口 + 历史加载；不换行
- [ ] 搜索分屏高亮 + 上下定位；自动翻页 ≤20 页
- [ ] 右键四项行为正确；建触发器预填
- [ ] 折叠行重复折叠 + 计数 + 展开还原正确
- [ ] 空格逐字保留、边框对齐（同 B5 约束文档）
