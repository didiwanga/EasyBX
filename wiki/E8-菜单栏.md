# 菜单栏设计（基础件其四）

> 主窗口 menuBar 完整菜单设计，配合 B9 工具栏、D4 多标签、窗口 dok。

## 一、菜单结构
### 文件 File
- 新建连接…（打开登录窗 D3）
- 断开当前连接
- 重新连接
- 分隔线
- 退出（关闭，托盘可收）

### 编辑 Edit（作用于当前标签输出）
- 查找…（Ctrl+F，B5 findbar）
- 清洁画面（B7/清洁）
- 字体设置…（等宽+缩放，B5）
- 分割视图（B5e 聊天气义）
- 清空输出

### 查看 View（各 dock/面板开关，勾选持久化）
- 触发器…
- 别名…
- 定时器…
- 宏…
- 脚本…
- 命令速查（B6 dock）
- 本地地图(D4)
- 世界地图
- 技能面板
- 托盘（停靠托盘）

### 工具 Tools
- 工具中心（宏控制 dock / 移动 dock 切换）
- 编码…（A2）

### 多账号 Accounts（D4）
- 切换标签（账号下拉）
- 新建/删除账号

### 脚本 Scripts
- 运行脚本…（弹出选择）
- 加载/保存（B8）

### 帮助 Help
- 关于（R，含 app.ico/app.png 与版本）
- 脚本 API 文档（B8《API Doc》）

## 二、快捷键预留（待「全局快捷键」设计补充）
- Ctrl+F 查找、Ctrl+W 关闭标签、Ctrl+N 新建连接等（快捷键独立文档留接口）

## 三、托盘/其它
- 顶部不显示菜单也可，保留 F11 全屏。

## 四、行为
- 菜单 action 触发 → 对应窗口/面板显示或 toggle。
- 集中处理，避免菜单散落（此文件是唯一入口）。
