# B7 状态栏（定稿）

## 状态栏项
| 项 | 内容 |
|----|------|
| 连接状态 | 已连接 / 连接中 / 重连中(倒计时/次数) / 中断 |
| 编码 | 当前 gbk/utf8/big5 |
| 账号 | 当前登录角色名/id |
| 定时器数 | 当前激活定时器数量 |

## 实时性
- 连接状态由 A4 驱动；编码由 A2 驱动；定时器计数由定时器引擎变化时刷新。
- GMCP.Status 变化的角色字段（可选）可附加显示在状态栏（如 qi/jing）。

## 布局
- 置于窗口底部，跟随主窗口缩放。

## 验收
- [ ] 四类信息实时准确
- [ ] 登录后显示账号名；重连时显示重连进度
## 渲染规约：进度条钳制（数据条通用）
- 游戏真实数据可能出现 当前值 > 最大值（如 精力 200/100），按真实值原样展示、**不干预**。
- 用进度条/百分比显示时，**钳制**：当前值 >= 最大值 → 恒显 100%；当前值 < 最大值 → 按 cur/max 实际比例渲染。
- 禁止溢出、负值、>100% 的异常条显示；文字数字仍显示真实值，仅条宽/百分比钳制。
