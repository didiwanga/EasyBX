# B9 自动化工具栏 + 停靠面板（定稿 v2）

## 目标
- 菜单下方增加全局工具栏。
- 三类停靠 dock：快捷动作 / 移动控制 / 宏控制。

## 工具栏按钮（与自动化菜单对应，打开编辑窗口，非开关）
| 按钮 | 作用 |
|------|------|
| 触发器 | 打开触发器编辑窗口（同菜单） |
| 别名 | 打开别名编辑窗口（同菜单） |
| 宏 | 打开宏编辑窗口（同菜单） |
| 定时器 | 打开定时器编辑窗口（同菜单） |
| Lua | 打开 Lua 脚本编辑器（同菜单） |
| **触发器开关** | 全局启停触发器，默认启用 |
| **定时器开关** | 全局启停定时器，默认启用 |
| **宏控制** | 打开宏控制 dock |

布局：左段 = 实体编辑入口按钮；右段 = 开关组；宏控制可归开关组或独立，中间以分隔符隔开。

## Dock 1：快捷动作
- 预设动作：详情(score)、技能(skills)、状态(hp)、背包(inventory)、逛逛(wander)。
- 支持**动态添加**快捷动作按钮（名称 + 命令）。
- 数据存储：预设写死代码，用户新增存本地配置文件，启动时合并（默认方案）。

## Dock 2：移动控制（GMCP 动态驱动）
- **3×3 九宫格**：四角 + 四边 = 八方向按钮，中央为「看(look)」。
- 八方向按钮图标固定为 ⬆️⬇️⬅️➡️↖️↗️↙️↘️（对应 n/s/w/e/nw/ne/sw/se 语义），但**发送命令按当前房间 GMCP 出口动态解析**：
  - 同一方向不会同时出现平向与垂直/斜向出口，故 ⬆️ 可无歧义映射到 north 或 northup。
  - 例：出口 northup;east;enter;down → ⬆️ 可用(发 northup)，➡️ 可用(发 east)，其余八方向键置灰禁用。
- **九宫格下边一行四键**：上/下/进/出，图标 ⬆️⬇️⤴️⤵️，对应 up/down/enter/out。
  - 例：出口含 enter 与 down → ⬇️(发 down)、⤴️(发 enter) 可用，其余置灰。
- 无对应出口的按钮：置灰 + 禁用。
- 数据源：GMCP Room.Info 的出口信息（GMCP 未启用/未知时按钮全禁用）。

## Dock 3：宏控制
- 宏列表。
- 控制按钮：运行宏 / 暂停 / 恢复 / 停止宏。
- 宏状态显示：宏步骤执行进度、已执行次数。
- 与「宏」编辑窗口分工：编辑窗口管理宏定义，宏控制 dock 负责运行与状态。

## 统一开关模型
- `trigger_on` / `timer_on` 全局布尔，工具栏开关一键启停，默认启用。
- 仅停用/启用该类实体执行，不删除子项；编辑窗口内子项可单独勾选。

## 依赖
- 无新增第三方依赖（QToolBar/QDockWidget 均为 Qt 内置）。
