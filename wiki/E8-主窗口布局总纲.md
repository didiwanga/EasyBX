# 主窗口布局总纲（基础件其三）

> 把已定稿的各模块（A/B/C/D/地图）串成完整主窗口骨架。所有 docking 可停靠/拖动/隐藏。

## 一、总体结构（自顶向下）
```
┌──────────────────────────────────────────────┐
│  菜单栏 (menuBar)                              │
│  工具栏 (toolBar: 触发器/定时器/宏/脚本/查找…)  │
├──────────────────────────────────────────────┤
│             QTabWidget 中央区 (D4多标签)        │
│   ┌────────────────────────────────────────┐ │
│   │ tab1 │ tab2 │ …（每账号一标签）           │ │
│   │ ┌────┬────────────────────┬─────┐      │ │
│   │ │左Dock│      主输出         │右Dock│───> dock
│   │ │地图 │    (B5, 主输出)     │命令s│    柱
│   │ │技能 │  ┌─────────────────┐│查找 │     |
│   │ │     │  │ 底部聊天(B5e)    ││     │     |
│   │ └─────┴──┴─────────────────┴┴─────┘      │ │
│   └──────────────────────────────────────────┘ │
├──────────────────────────────────────────────┤
│  状态栏 statusBar (B7 状态 + 底部消息条)        │
└──────────────────────────────────────────────┘
```

## 二、菜单栏 menuBar（待「菜单栏」单独细化，此处先列）
- 文件（新建连接/断开/退出）
- 编辑（查找/清洁/字体）
- 查看（触发器/别名/定时器/宏/脚本/命令速查/地图 开关）
- 工具（工具中心/状态栏）
- 帮助（关于/脚本 API 文档）

## 三、工具栏 toolBar
- 触发器/定时器/宏/脚本 打开编辑窗；宏控制开关；查找；命令速查；清洁；字体（见 B9）。

## 四、中央区 QTabWidget（D4）
- 每账号一个标签：连接/输出/状态/GMCP/本地地图都独立到该标签。
- 每标签内：主输出（中央更大）+ 底部聊天气义部（B5e）+ 左右 dock 自动化（命令速查/微地图/技能）。

## 五、Dock（QDockWidget，见 B9）
- 左侧：微地图(D4)、技能面板(D4每标签)
- 右侧：命令速查 B6、触发/别名编辑器打开处（不 dock，对话）
- 顶部浮动：宏控制 dock（B9）、移动 dock（3×3 方向）
- 全部 remember 停靠位置（layout.json）

## 六、状态栏 statusBar（B7）
- 左：连接状态/服务器/编码
- 中：人物状态简（血/mp/经验）
- 右：账号标签、创建/光标行列

## 七、多标签切换行为
- 顶部 tab 当前活动账号：状态栏/状态区显示其数据；对应 dock 内容随该标签切换（见 D4）。
- 自动化定义可见性按「账号共享」勾选；运行独立实例。

## 八、其它（托盘等留待主窗后）
- 托盘 minimizable 处理（留待主窗后）。
