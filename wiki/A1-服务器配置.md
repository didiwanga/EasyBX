# A1 服务器配置（定稿）

## 服务器配置模型
每条服务器配置字段：
| 字段 | 说明 |
|------|------|
| `name` | 显示名 |
| `host` | 主机/IP |
| `port` | 端口 |
| `encoding` | 默认编码 (gbk/utf8/big5) |

## 内置服务器（3 个）
| name | host | port | encoding |
|------|------|------|----------|
| 北侠 | mud.pkuxkx.net | 8080 | gbk（默认） |
| 北侠(UTF8) | mud.pkuxkx.net | 8081 | utf8 |
| 备用/本机 | 127.0.0.1 | 4000 | gbk |

## 默认值
- 首个默认服务器：8080 + GBK。
- 多账号：**已由 D4 多标签页取代**——一个主窗口多标签，每账号一标签，可同时登录多账号（此前版本「单窗口切换重连」作废）。

## UI
- 主界面可选服务器下拉 / 连接对话框新增服务器，配置持久化到本地配置文件。

- [ ] 内置 3 服务器可选；新增/编辑/删除服务器
