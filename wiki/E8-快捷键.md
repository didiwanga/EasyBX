# 全局快捷键设计（基础件收尾）

> 全部快捷键可自定义（预设默认，可在设置中改）；覆盖 全局/窗口内/输入框内 三个范围；连接多标签/编辑视图/自动化窗口/运行与移动 全预设。

## 一、范围与层级
| 范围 | 生效时机 | 示例 |
|---|---|---|
| **全局** | 任意时刻（含托盘） | Ctrl+Q 退出、连接 |
| **窗口内** | 主窗口/标签聚焦时 | Ctrl+F 查找、Ctrl+W 关标签 |
| **输入框内** | 输入框聚焦时 | 发送/历史/补全 |

- 同键位低层优先：输入框内 > 窗口内 > 全局（输入框拦截优先）。

## 二、自定义
- 所有快捷键存 `config.json`（全局）→ `keybinds` 段。
- **默认预设**内置；用户可在「设置→快捷键」中修改任意项为另一组合/功能/清除。
- 冲突检测：设置时若与其他项冲突，提示并允许覆盖或取消。

## 三、预设快捷键表
### 连接与多标签
| 动作 | 默认 |
|---|---|
| 新建连接/标签 | Ctrl+N |
| 关闭当前标签 | Ctrl+W |
| 切换下一标签 | Ctrl+Tab |
| 切换上一标签 | Ctrl+Shift+Tab |
| 断开当前连接 | Ctrl+Shift+D |
| 重新连接 | Ctrl+Shift+R |
| 退出 | Ctrl+Q |

### 编辑/视图
| 动作 | 默认 |
|---|---|
| 查找 | Ctrl+F |
| 查找下一个 | F3 |
| 清洁画面 | Ctrl+Shift+C |
| 清空输出 | Ctrl+L |
| 字体设置 | Ctrl+Shift+F |
| 分割视图 | Ctrl+Shift+V |

### 自动化窗口
| 动作 | 默认 |
|---|---|
| 触发器 | Ctrl+1 |
| 别名 | Ctrl+2 |
| 定时器 | Ctrl+3 |
| 宏 | Ctrl+4 |
| 脚本 | Ctrl+5 |
| 命令速查 | Ctrl+6 |
| 本地地图 | Ctrl+M |
| 世界地图 | Ctrl+Shift+M |

### 运行与移动（输入框/通用）
| 动作 | 默认 |
|---|---|
| 发送命令 | Enter |
| 命令历史上翻 | ↑ |
| 命令历史下翻 | ↓ |
| 补全 | Tab |
| 停止当前宏/脚本 | Esc |

## 四、实现
- `ShortcutManager`（单例，QObject）：
  - 注册 (action_name, 默认 shortcut, 范围, 回调)
  - `rebind(name, seq)` / `reset_all()` / `get(name)` / `apply()`（重启后应用 config）
  - 冲突检测 `validate(seq)`
- 用 QShortcut 或 QAction.setShortcut 绑定；输入框内用 keyPressEvent 拦截。

## 五、设置 UI
- 「设置→快捷键」表格：动作名 | 当前按键 | 修改（录制新组合）/重置。
- 实时应用；保存到 config.json。
