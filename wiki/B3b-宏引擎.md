# B3b 宏引擎（定稿）

## 整体模型
- **宏** = 名称 + 步骤序列（有序列表）+ 启用 + 归属（账号共享/绑定账号，沿用 D4）。
- **执行**：每用户标签全局**单宏串行**，一次只跑一个宏，不多线程并行跑多个宏。
- **步骤自消费**：等待类步骤（触发器/等待赋值）命中即**向下继续**，不重复停留；除非循环回来再次执行到该步，属于下一次循环，仅响应一次。因此不存在"重复触发"冲突。
- **控制**：运行 / 暂停 / 恢复 / 停止（工具栏宏控制 dock B9）。
- **状态**：当前步骤 / 步骤进度 / 执行次数（宏控制 dock 显示）。
- **时间单位**：全项目时间统一**毫秒**，UI 标注提示（如"延时（毫秒，1000=1秒）"）。

## 十一种步骤定义（定稿 v2：在七种基础上新增 8️⃣状态 9️⃣验证码 🔟判断分支 1️⃣1️⃣计数循环）

### 1️⃣ 命令步骤
- 发送一条命令到游戏（可含 `{变量}` 代入 + 多命令 `;` 拆分）。

### 2️⃣ 延时步骤
- 等待固定毫秒后继续下一步。

### 3️⃣ 标签步骤
- 给位置打标记，供跳转作为目标；**仅当前宏内有效**。
- 参数：标签名。

### 4️⃣ 跳转步骤
- 无条件或带条件跳转，目标为**标签名或步骤序号，必须从"已有的下拉"选择，不可自定义**（避免运行找不到目标报错）。
- 参数：目标（标签/序号下拉）+（可选）条件。

### 5️⃣ 判断步骤
- 条件分支：对条件判断真/假，分别继续到不同位置。
- **条件类型**：
  - 包含文本
  - 匹配正则
  - 变量值比较：格式 `{变量} +（=、≠、＞、＜）+ 比较值`
    - 如 `{v01}=长安`、`{v01}<30`、`{v01:color}=#FF0000`
- **真分支 / 假分支**（各含，去向与动作）：
  - 去向：标签 / 步骤序号（下拉已有）
  - 动作：变量赋值 / 发送命令（可带 `{变量}`）
- 用户可「➕」添加多个条件，条件关系选择 **与(全与) / 或(全或)**。

### 6️⃣ 等待赋值步骤
- **阻塞，弹出输入窗口等待用户输入**，输入内容赋给指定变量。
- 参数：要赋值的变量、赋值提示词（如"口令"）、超时（默认 0 = 永不超时）。
- 若超时>0：超时后**弹窗自动关闭并继续下一步骤**。

### 7️⃣ 触发器步骤（复用 B3 触发器设计）
- 语义同触发器，阻塞等待服务器条件命中并捕获变量后继续。
- **一个触发条件可同时获取多个变量**（以条件中写的变量数量为准）。
- **多条件赋值**：触发条件多个时按与/或关系：
  - **与**：各条件中的变量**都**赋值。
  - **或**：仅有唯一命中的条件中的变量赋值。
  - 此规则**同样适用于触发器 B3 的设计**。

### 8️⃣ 状态比较步骤
- 对 GMCP 已获取的状态属性（气血/内力/食物/战意/真气/真元等，下拉 _STATUS_ATTRS）做比较判断。
- 参数：状态属性（下拉）+ 运算符（=、≠、＞、＜、≥、≤）+ 比较值（可含 `{变量}`）。
- **满足 / 不满足**：与判断步骤相同，各含「去向（标签/序号下拉）+ 动作（变量赋值/发送命令）」。
- 匹配时引擎用 `session.state` 属性取值比较。

### 9️⃣ 验证码步骤
- 弹验证码窗口（CaptchaWindow），等待用户输入验证码回传给宏。
- 参数：发送命令（如 `fullme`）+ 变量名（回填验证码，默认 `code`）+ 检测超时。
- **不等待服务器回话**：提交即关窗，验证码赋值给变量后继续下一步。

### 🔟 判断分支步骤（branch）
- 通用条件分支：可选触发条件（B3 条件列表，可含状态比较）+ 关键字列表。
- 每个关键字（命中行需包含的文本）映射一个动作：发送命令 / 跳转步骤 / 变量赋值。
- 参数：触发条件(可空) + 关键字列表 + 命中后延时 + 等待超时。
- 等待触发条件/关键字命中时：命中即延时执行动作；超时继续下一步。

### 1️⃣1️⃣ 计数循环步骤（loop）
- 循环跳回指定起点（已有标签或步骤序号下拉）执行 N 次；`count=0` = 无限循环。
- 引擎维护 `_loop_count`，循环次数用尽后向下继续（防死循环超出设定的范围）。

## 5a 宏控制 dock（补全 B9）
- 宏列表：所有宏（名称 + 归属标记），当前运行宏高亮。
- 控制按钮：
  - ▶ 运行当前选中宏（已在运行 → 提示）
  - ⏸/▶ 暂停 / 恢复
  - ■ 停止（停止后状态复位）
- 状态显示：
  - 当前步骤：步骤名/序号（如 `步骤 5/12`）
  - 进度条：当前序号 / 总步骤数
  - 执行次数：本次运行已执行计数
- 运行中等待（等待赋值/触发器阻塞时）步骤名变灰/闪烁提示。

## 5b' 宏录制（单独漂浮 dock）
- **独立漂浮 dock 控制录制**：开始 / 暂停 / 恢复 / 停止录制。
- 录制来源：**命令框 + 快捷动作 dock + 移动控制 dock** 发出的命令均被录制。
- **仅录制移动**选项：勾选后自动仅判断并录制移动命令。
- **实时编辑**：录制中可实时增删改步骤（删除多余/错误步骤、添加任意步骤类型）。
- **命令步骤合并**：录制得到的命令累积合并到**单个命令步骤**，内部 `;` 分隔合成单行多命令；**除非用户实时插入步骤**，插入后后续命令进入新的命令步骤，以此类推。

## 5c 命令步骤「反转命令」按钮
- 反转功能**不施加于整个宏**，仅针对**单个命令步骤编辑框**：
  - 命令步骤编辑框旁放置「反转命令」按钮。
  - 点击反转**该命令编辑框内的命令序列**：
    1. 命令顺序倒序；
    2. 每条命令若为**移动方向**则换成相反方向（west→east、northup→southdown、up→down、enter→out 等）。
- 示例：`east;north;west` 反转 → `east;north;east`。

## 5b 宏编辑器
- 主区：步骤序列列表（增删 / 上下移 / 拖拽排序）。
- 选中步骤 → 表单动态编辑该步骤参数（按类型切换）。
- 顶部：宏名称、启用、归属（账号共享/绑定账号，D4）。
- 按钮：新增步骤（选类型）/ 删除 / 上移 / 下移。
- 不做测试运行（已确认取消）。
- 各步骤表单按十一种类型动态显示（命令文本/延时毫秒/标签名/跳转下拉+条件/判断条件列表+与或+真假分支/等待赋值变量+提示词+超时/触发器复用 B3 表单/状态属性下拉+比较/验证码命令+变量/分支关键字列表/循环起点下拉+次数）。
